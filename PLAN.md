Единственный источник правды по задачам. Выполненное отмечаем `[x]` и удаляем при очередной чистке,

## Цель

Зеркалить папки Яндекс Диска на домашний сетевой диск, держать их одинаковыми
и забрать фото из безлимитного хранилища Яндекса.

## Архитектура (черновик)

- `settings` - конфигурация из окружения.
- `yandex` - клиент API, ничего не знает о синхронизации.
- `storage` - абстракция над локальной папкой/сетевым диском.
- `state` - снимок прошлой синхронизации.
- `engine` - чистая логика: два списка файлов + снимок на входе, список действий на выходе (легко тестировать).
- `cli` - запуск, `--dry-run`, режим демона.

Код без комментариев: смысл несут имена и докстринги (Google-стиль).
